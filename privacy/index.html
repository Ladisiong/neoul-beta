개인정보 처리방침

BHTM Holdings(이하 '회사')는 학습 관리 서비스 너울(NEOUL)을 운영하며, 개인정보보호법에 따라 이용자의 개인정보를 보호합니다. 이 방침은 회사가 실제로 저장하는 데이터를 기준으로 작성했습니다.

시행일 2026년 9월 8일. 변경 시 이 페이지에 개정 내용과 시행일을 함께 공지합니다.

2. 수집·이용 목적

  • 서비스 제공 — 복습 일정 자동 배치, 취약 개념 진단, 퀴즈 생성·채점, 단권화 노트 생성
  • 회원 관리 — 본인 확인, 가입 의사 확인, 부정 이용 방지, 문의 응대
  • 학부모 리포트 — 학부모가 연동한 경우에 한해 자녀의 학습 현황 제공
  • 요금 정산 — 유료 구독의 결제·환불 처리
  • 서비스 개선 — 기능 이용 통계 분석 (개인을 식별하지 않는 형태로 처리)
  • 마케팅 정보 발송 — 별도로 동의한 이용자에 한하여 이벤트·소식 안내

4. 만 14세 미만 아동

회사는 만 14세 미만 아동의 회원가입을 받지 않습니다. 가입 시 만 14세 이상임을 확인하며, 만 14세 미만임이 확인되면 해당 계정과 수집된 정보를 지체 없이 파기합니다. 만 14세 미만 자녀의 이용을 원하는 경우 법정대리인의 동의 절차가 필요하므로 아래 연락처로 문의해 주십시오.

6. 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

  • 이용자가 사전에 동의한 경우 (예: 학부모 연동을 승인한 경우 자녀의 학습 현황을 해당 학부모에게 제공)
  • 법령에 따라 수사기관이 적법한 절차로 요구하는 경우

7. 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다. 서비스 내 설정 또는 아래 연락처를 통해 요청하실 수 있으며, 회사는 10일 이내에 처리하고 결과를 알려드립니다.

  • 개인정보 열람 요구
  • 오류가 있을 경우 정정 요구
  • 삭제 요구 (법령상 보존 의무가 있는 항목 제외)
  • 처리 정지 요구
  • 마케팅 수신 동의 철회
  • 회원 탈퇴 — 서비스 내에서 직접 처리 가능

만 14세 미만 아동의 법정대리인은 아동의 개인정보에 대해 위 권리를 대신 행사할 수 있습니다.

8. 안전성 확보 조치

  • 접근 통제 — 모든 데이터 테이블에 행 수준 보안(Row Level Security)을 적용해, 이용자는 자신의 데이터에만 접근할 수 있습니다
  • 비밀번호 암호화 — 복호화가 불가능한 방식으로 저장합니다
  • 전송 구간 암호화 — 모든 통신에 HTTPS를 적용합니다
  • 접근 권한 최소화 — 개인정보 취급자를 최소한으로 지정하고 권한을 분리합니다
  • AI 키 서버 보관 — AI API 키는 서버에서만 사용하며 이용자 브라우저에 노출하지 않습니다

9. 쿠키 및 유사 기술

회사는 로그인 상태 유지와 이용 통계 분석을 위해 쿠키와 브라우저 저장소를 사용합니다. 이용자는 브라우저 설정에서 쿠키 저장을 거부할 수 있으나, 이 경우 로그인이 필요한 기능의 이용이 제한될 수 있습니다.
